This folder contains original MATLAB code for the two CH5030 assignments.

No external dataset is required. All numerical data are generated by the MATLAB programs:

- Assignment 1 generates pseudo-random number streams and tests them.
- Assignment 2 generates Ising spin configurations using Monte Carlo simulation.

## Files

- `assignment1_random_generators.m`
  - Linear congruential generators
  - Shift-register generator
  - Mean test
  - Runs test
  - Comparison with MATLAB Mersenne Twister
  - Curve Fitting Toolbox analysis of empirical CDF behavior, with fallback if unavailable

- `assignment2_ising_glauber.m`
  - Glauber Metropolis simulation for square Ising lattices
  - Lattice sizes `32`, `64`, and `128`
  - Field cases `B/kT = 0` and `B/kT = 0.5`
  - Magnetization, susceptibility, and specific heat per spin
  - Curve Fitting Toolbox smoothing of simulation curves, with fallback if unavailable

## How to run

Open MATLAB in this folder and run:

```matlab
assignment1_random_generators
assignment2_ising_glauber
```

The second assignment is computationally heavier. Defaults are 500 equilibration sweeps and 1000 sampling sweeps per `J/kT` value. The L = 128 case will take a while; reduce these constants in `assignment2_ising_glauber.m` for a quicker draft, or raise them for a cleaner χ peak near criticality.

## Assignment 2 sign convention

`assignment2_ising_glauber.m` uses `pairEnergySign = -1` by default, which
is the standard ferromagnetic Ising convention:

```text
E = -J sum(si sj) - B sum(si)
```

This produces the expected order-disorder transition near `J/kT ~ 0.44`.
If your instructor expects the literal sign written in the PDF
(`E = +J sum(si sj) - B sum(si)`, antiferromagnetic), set
`pairEnergySign = +1` at the top of the script.
